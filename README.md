# Wildhearth

A cosy Fabric mod for **Minecraft Java 26.3**: seasons, rivers and weather that change the land; wild deer, boar, reindeer, porcupines, badgers, chipmunks and shy forest elves; real farming with seed saving, beekeeping and mead; livestock breeds; caves full of glow-worms, hot springs and goblins; folk festivals; and field guides for all of it.

**[Read the Wildhearth wiki](https://luekg15-hue.github.io/living-world-releases/)**: every field guide page, creature, item and recipe.

## Download

Get the latest jar from [Releases](../../releases/latest).

## You need

| | Version |
|---|---|
| Minecraft Java Edition | 26.3 |
| Fabric Loader | 0.20.1 or newer ([installer](https://fabricmc.net/use/installer/)) |
| Fabric API | 0.165.2+26.3 or newer for 26.3 ([Modrinth](https://modrinth.com/mod/fabric-api)) |
| Java | 25 (the official launcher brings its own) |

## Install

1. Run the Fabric installer, choose Minecraft 26.3, click Install.
2. Put the Wildhearth jar and the Fabric API jar in your `mods` folder:
   - Windows: `%appdata%\.minecraft\mods`
   - Mac: `~/Library/Application Support/minecraft/mods`
   - Linux: `~/.minecraft/mods`
3. In the Minecraft launcher pick the `fabric-loader-26.3` profile and play.

Playing together: everyone, including the host or server, needs the same two jars. Start a new world to see rivers, rapids and the new animals.
